# calcore
 calcoreは日付表記を用いて書く難解プログラミング言語です。  
## 言語仕様
- インタプリタ型
- 以下の対応した日付形式の中の一つでコマンド・数値・文字を書く
     - YYYY/MM/DD
     - YYYY.MM.DD
     - YYYY-MM-DD
     - MM/DD/YYYY
     - MM.DD.YYYY
     - MM-DD-YYYY
     - DD/MM/YYYY
     - DD.MM.YYYY
     - DD-MM-YYYY
- コマンドはMMとDDの部分で識別しますが、コマンドを書くときはYYYYを含む表記で書く
- 数値は2000年1月1日を0として基準に何日たったかを数値とする。(1999年以前は負の整数となる。)
- 文字は、unicodeのコードポイント(10進数)の数値を入力することで代入できる。
- 変数はメモリテープで扱います。
- コードの最初に日付表記を書く。その下から、プログラムを書く
- コマンドと引数、引数と引数の間は半角スペースを用います。
- コマンドと次のコマンドは改行で仕切ります。
- コメントは、先頭に#を入れます。
- コードファイルの拡張子は`.clc`です。

## コマンド一覧
|命令（MM/DD）|動作|説明|
|---|----|---|
|1月|||
|1/1|入力|入力から1行を読み込み、一文字ずつunicodeのコードポイントに変換し、変数に格納する。各文字を格納するたび、ポインタを一つずつ進めながら順に書き込む。書き込みが終了すると、ポインタは元の位置に戻る|
|1/2|出力用変数に格納|ポインタ先の変数を出力用変数の文字列の未尾に追加|
|1/3|出力用変数を出力|出力用変数を出力し、出力用変数を初期化する|
|1/4|無条件ジャンプ|実行位置を引数1の変数番目の値に移動する。|
|1/5|条件ジャンプ(==)|引数1の値==引数2の値　がtrueなら実行位置が引数3の変数の値番目に移動する。また、falseなら、引数4がない場合は、スルーし、引数4があれば、実行位置が引数4の変数の値番目に移動する。|
|1/6|条件ジャンプ(<)|引数1の値<引数2の値　がtrueなら実行位置が引数3の変数の値番目に移動する。また、falseなら、引数4がない場合は、スルーし、引数4があれば、実行位置が引数4の変数の値番目に移動する。|
|1/7|条件ジャンプ(>)|引数1の値>引数2の値　がtrueなら実行位置が引数3の変数の値番目に移動する。また、falseなら、引数4がない場合は、スルーし、引数4があれば、実行位置が引数4の変数の値番目に移動する。|
|1/8|条件ジャンプ(<=)|引数1の値<=引数2の値　がtrueなら実行位置が引数3の変数の値番目に移動する。また、falseなら、引数4がない場合は、スルーし、引数4があれば、実行位置が引数4の変数の値番目に移動する。|
|1/9|条件ジャンプ(>=)|引数1の値>=引数2の値　がtrueなら実行位置が引数3の変数の値番目に移動する。また、falseなら、引数4がない場合は、スルーし、引数4があれば、実行位置が引数4の変数の値番目に移動する。|
|2月||
|2/1|数値型の変数を宣言|引数が指定した数値をポインタ先に代入する|
|2/2|文字型の変数を宣言|引数が指定した文字をポインタ先に代入する|
|2/3|変数のポインタの移動(絶対移動)|ポインタを引数番目に移動する|
|2/4|変数のポインタの移動(相対移動)|ポインタを引数分、移動する|
|2/5|変数のポインタの移動(絶対移動)|ポインタを引数番目にある変数の値の番目に移動する|
|2/6|変数から変数へコピー|ポインタ先の変数に引数番目の変数を代入する|
|2/7|ポインタ数を変数へコピー|引数番目の変数にポインタ数を代入する|
|2/8|数値型から文字型へ変換する|ポインタ先の変数が文字列型になる|
|2/9|文字型から数値型へ変換する|ポインタ先の変数が数値型になる|
|2/10|変数から変数へコピー|引数番目の変数にポインタ先の変数を代入する|
|2/11|変数の型を取得|ポインタ先の変数の型を引数番目の変数に代入する。数値型だと1、文字型だと2、値がない場合は0|
|3月|||
|3/1|足し算|引数1の変数+引数2の変数をポインタ先の変数に代入する|
|3/2|引き算|引数1の変数-引数2の変数をポインタ先の変数に代入する|
|3/3|掛け算|引数1の変数*引数2の変数をポインタ先の変数に代入する|
|3/4|割り算|引数1の変数/引数2の変数をポインタ先の変数に代入する|
|3/5|割り算のあまり|引数1の変数%引数2の変数をポインタ先の変数に代入する|
|4月|||
|4/1|出力用変数を初期化する|出力用変数の内容を削除する|
|4/2|今の年数|今の年数を数値型でポインタ先の変数に代入します(1000~9999)|
|4/3|今の月数|今の月数を数値型でポインタ先の変数に代入します(1~12)|
|4/4|今の日数|今の日数を数値型でポインタ先の変数に代入します(1~31)|
|4/5|今の曜日|今の曜日を数値型でポインタ先の変数に代入します(0:日曜日～6:土曜日)|
|4/6|今の時刻|今の時刻を数値型でポインタ先の変数に代入します(0~23)|
|4/7|今の分数|今の分数を数値型でポインタ先の変数に代入します(0~59)|
|4/8|今の秒数|今の秒数を数値型でポインタ先の変数に代入します(0~59)|
|4/9|今のミリ秒数|今のミリ秒を数値型でポインタ先の変数に代入します(0~999)|
|4/10|今日の日付を数値として変数にいれる|今の日数を2000/1/1から何日経ったかを計算して数値型でポインタ先の変数に代入します。|

コマンドのYYYYは適当の数字、または文字列。  
プログラムが終了しても、出力用変数に値が入っていた場合、出力用変数の値が出力されます。  
ジャンプの実行位置は、最初の行(日付表記)を1して、何番目にあたるかを指定する。

## コード例
```
YYYY/MM/DD
2025/2/1 2000/1/6 #変数作成（数値）　5　(ポインタ0)
2025/2/4 2000/1/2 #変数ポインタに1を足す
2025/2/1 2000/1/7 #変数作成(数値) 6 (ポインタ1)
2025/2/3 2000/1/1 #変数ポインタを0にする
2025/1/2          #出力(ポインタ0)
2025/1/3	       #出力改行
2025/2/4 2000/1/2 #変数ポインタに1を足す
2025/1/2　　　　　#出力(ポインタ1)
2025/1/3          #出力改行
2025/2/4 2000/1/2 #変数ポインタに1を足す
2025/3/1 2000/1/1 2000/1/2 #変数0の数+変数1=変数ポインタ(ポインタ2)
2025/1/2	       #出力(ポインタ2)
2025/1/3          #出力改行
```
出力  
5  
6  
11  

他のコード例は`example`にあります。
