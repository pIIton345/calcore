# calcore
 calcoreは日付の書式を用いた難解プログラミング言語です。  
## 言語仕様
- インタプリタ型
- YYYY/MM/DD形式(日付書式)でコマンド・数値・文字を書く
- コマンドはMM/DDの部分で識別する
- 数値は2000/1/1を0として基準に何日たったかを数値とする。(1999年以前は負の整数となる)
- 文字は、unicodeのコードポイントの数値を入力することで代入できる。
- 変数はメモリテープで扱います。
- コマンドと引数、引数と引数の間は半角スペースを用います。
- コメントは、先頭に//を入れるとできます。
- コードファイルの拡張子は`.clc`です
- 気が向いたら、YYYY.MM.DD形式など他の日付形式に対応したいと思います。

コマンドは、YYYY/MM/DDの形で書き、YYYYは適当の数字、または文字列。  
プログラムが終了しても、出力用変数に値が入っていた場合、出力用変数の値が出力されます。

※1/1を実行すると、実行すると、入力ダイアログが表示され、入力し、エンターキーを押すと、入力が完了になり、実行が進みます。入力した値が文字列が含んでいなく、数値ならポインタ先の変数に数値が代入されますが、文字列が含むと、一文字ずつ、ポインタが1ずつズレながら、代入されます。

## コード例
```
2025/2/1 2000/1/6 //変数作成（数値）　5　(ポインタ0)
2025/2/4 2000/1/2 //変数ポインタに1を足す
2025/2/1 2000/1/7 //変数作成(数値) 6 (ポインタ1)
2025/2/3 2000/1/1 //変数ポインタを0にする
2025/1/2          //出力(ポインタ0)
2025/1/3	       //出力改行
2025/2/4 2000/1/2 //変数ポインタに1を足す
2025/1/2　　　　　//出力(ポインタ1)
2025/1/3          //出力改行
2025/2/4 2000/1/2 //変数ポインタに1を足す
2025/3/1 2000/1/1 2000/1/2 //変数0の数+変数1=変数ポインタ(ポインタ2)
2025/1/2	       //出力(ポインタ2)
2025/1/3          //出力改行
```
出力  
5  
6  
11  

他のコード例は`example`にあります。
